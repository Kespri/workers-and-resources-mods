Welcome to the repository. This is a collection of custom assets, building models, and advanced script modifications designed to seamlessly integrate with modern, external community mod loaders.

## 🛠️ Technical Features
* **Mod-Loader Compatible**: Structured and packaged specifically to support advanced loader hooks and script injections.
* **Clean File Architecture**: Separate modules for easy management, debugging, and updating.
* **Performance Focused**: Highly optimized 3D assets and scripts to prevent late-game performance drops.

## 🚀 Installation & Setup

### Prerequisites
Ensure you have the latest version of your preferred community mod loader installed and configured for *Workers & Resources: Soviet Republic*.

### Setup Instructions
1. Download the repository as a ZIP file (click **Code** > **Download ZIP**).
2. Extract the contents to a temporary folder.
3. Move the respective mod folder into your dedicated mod-loader folder or the local game staging directory:
   `...\SovietRepublic\media_soviet\`
4. Launch the game via your mod manager to initialize the scripts.

## 🐛 Bug Reports & Feedback
If you encounter any script conflicts, missing textures, or crashes, please open an **Issue** on GitHub. Include your game version and the list of active mods for quicker troubleshooting.
