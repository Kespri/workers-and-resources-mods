Willkommen in diesem Repository. Hier findest du eine Sammlung von benutzerdefinierten Objekten, Gebäudemodellen und erweiterten Skript-Modifikationen, die speziell für die nahtlose Integration mit modernen, externen Community-Mod-Loadern entwickelt wurden.

## 🛠️ Technische Details
* **Mod-Loader-kompatibel**: Speziell so strukturiert und verpackt, dass er erweiterte Loader-Schnittstellen und Skript-Injektionen unterstützt.
* **Saubere Dateistruktur**: Getrennte Module für einfache Verwaltung, Fehlersuche und Updates.
* **Performance-optimiert**: Hochgradig optimierte 3D-Modelle und Skripte, um Performance-Einbrüche im späteren Spielverlauf zu verhindern.

## 🚀 Installation & Einrichtung

### Voraussetzungen
Stelle sicher, dass die neueste Version deines bevorzugten Community-Mod-Loaders für *Workers & Resources: Soviet Republic* installiert und eingerichtet ist.

### Installationsanleitung
1. Lade das Repository als ZIP-Datei herunter (klicke oben rechts auf **Code** > **Download ZIP**).
2. Entpacke den Inhalt in einen temporären Ordner.
3. Verschiebe den jeweiligen Mod-Ordner in deinen dedizierten Mod-Loader-Ordner oder in das lokale Entwicklungsverzeichnis des Spiels:
   `...\SovietRepublic\media_soviet\`
4. Starte das Spiel über deinen Mod-Manager, um die Skripte zu aktivieren.

## 🐛 Fehlerberichte & Feedback
Falls du auf Skriptkonflikte, fehlende Texturen oder Abstürze stößt, eröffne bitte ein **Issue** hier auf GitHub. Gib am besten deine Spielversion und eine Liste deiner aktiven Mods an, um die Fehlersuche zu beschleunigen.
